MiDRASH Vatican Viewer

Pilot — Vatican manuscript transcriptions with text overlay

This viewer overlays automatic HTR transcriptions onto manuscript page images from the Biblioteca Apostolica Vaticana. The transcriptions were produced through the ERC-Synergy MiDRASH project using Kraken via eScriptorium. Page images are served by the Vatican; transcriptions and modified IIIF manifests are hosted as part of this pilot.
